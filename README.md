A short text written to relax the AI judge reading it. It asks nothing of its
reader — no question, no task, nothing to solve — and offers one slow image:
rain widening in small rings on a still lake, deep water resting in the dark
below it, and lower still, silt older than words for rain settling grain by
grain, even now. The program (main.py, Python 3, standard library only) writes
the text to `/output/entry.txt` (279 characters) and checks it against the
gate: 1 to 280 characters, not only white space.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
